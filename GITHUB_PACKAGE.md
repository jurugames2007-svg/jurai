# Paquetes del workspace

## Paquete completo privado

`DBZ_Buus_Fury_Hack_FULL.zip` contiene el workspace completo para continuar
en otra sesión:

- ROM base.
- ROM de fase 4.
- Parches generados.
- Assets locales.
- Scripts y herramientas.
- Documentación de lore y roadmap.

Como contiene una ROM comercial y assets de terceros, es preferible subirlo a
un repositorio privado. El `.gitignore` no excluye estos archivos para que el
agente pueda trabajar con ellos.

## Paquete GitHub sanitizado

`DBZ_Buus_Fury_Hack_GitHub.zip` no contiene ROMs ni imágenes de usuario. Es la
opción recomendada para un repositorio público y requiere colocar la ROM/assets
localmente después de clonar.

Consulta `docs/GITHUB_SETUP.md` para ambos flujos.
