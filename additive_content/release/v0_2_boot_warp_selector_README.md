# LOG4 v0.2 Boot Warp Selector

Recommended ROM:

```text
roms/DBZ_LOG4_v0_2_BootWarpSelector.gba
```

Controls:

- Up/Down: select warp point.
- A/Start on Original: boot Buu's Fury.
- A/Start on Super/GT/AF/LOG1/LOG2: open that route/dimension debug screen.
- B: return to menu.
- Start on route screen: boot Buu's Fury.

Current limitation: route/dimension options are debug screens. Native map transitions are the next hook.
